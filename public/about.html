About CodeCraft

Empowering students and developers with automated logic verification and rubric-driven feedback.

🎯

Our Mission

  • • Provides instant automated evaluation across Algorithms, Flowcharts, and Pseudocode.
  • • Check loops: checks loop termination invariants and boundary safety.
  • • Computes Big-O notation for time and space complexity.
  • • Suggests clean and optimized implementations in seconds.
💡

What should a good code have?

  • • Manage Time Complexity: Ensure operations scale efficiently without slow nested loop bottlenecks.
  • • Manage Space Complexity: Minimize auxiliary memory and avoid unnecessary array cloning or string recreation.
  • • Suggest Clean & Optimized Code: Provide clear, readable, and structured logic with early return guards.
  • • Error-Free Execution: Ensure the code does not have syntax bugs, index out-of-bounds, or accidental assignments.
  • • Check Loop Termination: Enforce strict boundary conditions to completely prevent infinite loop freezes.

How the Website Runs

From code input to database storage and feedback generation:

01

Client Submission

The student inputs an Algorithm, Flowchart, or Pseudocode into the workspace form and clicks "Run Evaluation".

02

Express Backend Route

Express catches the POST request at /api/evaluate, reading the payload using req.body.

03

Evaluation & Bug Checks

The engine scans for loop bounds (off-by-one errors), infinite loops, and computes Time Complexity (Big-O).

04

SQL Database Storage

The evaluation results and scores are securely stored in the SQLite database for permanent history tracking.

05

Result Extraction

Checks errors, sends error-free code, and allows students to instantly extract and print results.
